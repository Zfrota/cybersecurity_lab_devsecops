# Discovery model record

- **Model:** Gemini, used via the public Gemini web app (gemini.google.com)
  in its default/automatic mode selection — no specific model tier (e.g.
  Pro/Flash) was manually chosen; Gemini's own backend auto-routing picked
  the model for each response.
- **Date used:** 2026-11-05
- **Settings:** default chat settings. No saved memory, custom instructions,
  or connected sources were enabled. Each of conditions A, B, and C was run
  in its own fresh conversation, as required by Section 3.
- **Interface:** plain chat interface (gemini.google.com), not an IDE
  assistant, coding agent, or API call with tool access — no repository or
  file-system access was given to the model; only the pasted source file
  and the designated prompt/context text for each condition.
