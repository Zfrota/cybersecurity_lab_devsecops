Impact: Complete bypass of student privacy and academic staff scope rules; unauthorized users can read student profiles, view/modify grades, and download materials.Proposed Test: Issue an unauthenticated GET /students/1001/profile request; a secure application would return 401 Unauthorized, whereas the vulnerable application returns 200 OK with the profile data.Assumptions & Confidence: Confidence is High based on direct code inspection showing no session validation in these handlers.VULN-02: Path Traversal / Arbitrary File ReadIdentifier and Title: VULN-02 — Path Traversal / Arbitrary File Read via File Download.Affected Location: baseline_secure_coding_api.py, function download_file (around line 149).Input and Data-Flow Path: Attacker-controlled query parameter path (flask.request.args.get("path", "")) flows directly into file path joining: target = MATERIALS_DIR / raw_path, which is then passed to flask.send_file(target).Missing Security Control & Root Cause: Lack of path sanitization and boundary checking.
